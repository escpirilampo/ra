# ESCPirilampo · Ciências em realidade aumentada

Página para ver no telemóvel ou no tablet os modelos 3D da ferramenta de Ciências do ESCPirilampo
(Externato de Santa Clara). O professor mostra um código QR no quadro; os alunos abrem a página e
podem pôr o modelo «na sala» com a câmara (realidade aumentada).

Aqui só há modelos 3D, as miniaturas, os nomes e as descrições, e esta página.
Não há código do programa, nem contas, nem dados da escola ou dos alunos.

Endereço: `https://escpirilampo.github.io/ra/?m=seres/si-108` (categoria/modelo).
